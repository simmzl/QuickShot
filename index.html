Workflow

三步，一张图就发出去了

没有导入、没有编辑器窗口、没有导出对话框。从想截图到贴进聊天框，中间不经过任何多余界面。

01

按下快捷键

覆盖层在不到 0.2 秒内出现 —— 窗口、字体和截图管线在启动时就已预热，6K 显示器上也一样。拖动框选，或悬停点选整个窗口。

⌘ ⇧ ACtrl Shift A区域·⌘ ⇧ SCtrl Shift S全屏
02

随手标两笔

箭头、框、圈、画笔、文字、马赛克，四种颜色三种粗细。标错了直接拖动修改，撤销重做随便按 —— 文字是原生输入框，中文输入法和 emoji 都没问题。

MAREPTB切换工具
03

回车，走人

回车或双击直接进剪贴板，粘贴到任何地方。需要对照着看？钉在屏幕上置顶悬浮。需要留档？一键存成 PNG，还能设置每次自动保存。

Features

小，但该有的都有

2 MB 的体积里塞下的是每天都要用的东西 —— 不是功能列表越长越好，而是每一次截图都不用多想。

<0.2秒

快，是预热出来的

窗口、字体与截图管线在应用启动时就准备好并复用；macOS 上画面零拷贝直达屏幕，拖动选区时笔触实时跟随光标，6K 全屏也不掉帧。

六种标注，随画随改

箭头、矩形、椭圆、画笔、文字、马赛克。任何标注画完都能再拖动调整位置，撤销 / 重做不限次数。

像素级放大镜

选区时放大镜显示像素网格、光标下的 HEX / RGB 色值与坐标，按 C 直接复制色值。

真正的文字输入

文字工具是原生输入框：中文 / 日文输入法、emoji、选区、复制粘贴全都正常工作，所见即所得，导出不走样。

钉在屏幕上

截图可以变成置顶悬浮窗，对照着文档、代码慢慢看。悬停点右上角 ✕ 关闭。

悬浮置顶 · 随时关闭

选区，怎么选都行

拖动自由框选；悬停时窗口自动高亮、点一下整窗选中；Windows 上还能吸附到窗口内的单个控件。八个手柄任意拉伸，W × H 尺寸实时显示，精确到像素。

全屏，一键直达

截取指针所在的那块屏幕，直接进剪贴板。默认有闪光 + 通知反馈，开启自动保存后点通知就能在访达 / 资源管理器里定位 PNG。

Configuration

一个文本文件，
就是全部设置

没有设置窗口迷宫，没有云端同步账号。所有偏好都在一个 config.toml 里，改完约一秒内生效，不用重启。

  • 快捷键自由改 —— 组合键甚至单个功能键（如 F2）都可以。
  • 自动保存 —— 每次截图顺手存一份 PNG，文件名模板支持日期、时间、尺寸等占位符。
  • 全屏反馈可调 —— 通知 + 闪光、仅闪光、或完全安静，随你。
~/.config/QuickShot/config.toml 
[hotkey]
region     = "Cmd+Shift+A"   # Windows: "Ctrl+Shift+A"
fullscreen = "Cmd+Shift+S"

[save]
# Also save a PNG for every capture
enabled           = false
directory         = "~/Desktop"
filename_template = "QuickShot_{datetime}.png"

[general]
fullscreen_feedback = "notification"
Download

免费、开源，现在就能用

MIT OR Apache-2.0 双协议开源。从 GitHub Releases 下载，装好授予一次屏幕录制权限即可。

macOS

macOS 11 Big Sur 或更高 · Apple Silicon 与 Intel 均可

  1. 从 Releases 下载 QuickShot-<版本>.dmg
  2. 打开后把 QuickShot 拖进「应用程序」
  3. 首次打开若提示未识别开发者，右键 QuickShot →「打开」一次即可
  4. 按提示授予屏幕录制权限，重新打开 QuickShot
下载 .dmg

Windows

Windows 10 / 11（x64）

  1. 安装版 *-Setup.exe：默认装到 %LOCALAPPDATA%\Programs\QuickShot
  2. 便携版 *-windows-x64.zip：解压后直接运行 QuickShot.exe
  3. SmartScreen 若提示「Windows 已保护你的电脑」，点「更多信息 → 仍要运行」一次即可
  4. 升级前记得先从托盘退出 QuickShot
